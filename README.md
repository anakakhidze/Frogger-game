# Frogger (Lua)

A classic 2D arcade Frogger clone built using **Lua** and the **LÖVE (Love2D)** framework.

## 🎮 Gameplay & Features

* **Classic Arcade Mechanics:** Dodge oncoming traffic, ride floating logs, and navigate water hazards.
* **Audio & Custom Fonts:** Dynamic sound effects for movements and game events paired with retro arcade typography.
* **Score & Lives System:** Earn points as you advance through obstacles while managing a 3-life safety margin.
* **Fluid Grid Movement:** Discrete, responsive step movement matching original arcade gameplay.

## 🛠️ Built With

* **[Lua](https://www.lua.org/):** Core game logic, state management, and movement math.
* **[LÖVE (Love2D)](https://love2d.org/):** 2D game engine handling rendering, input, and game loops.
